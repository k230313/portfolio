Managing Users in Active Directory

Adamson Buliboli | Dec 11, 2025 min read

Why Learn User Management in Active Directory

Managing user accounts is one of the most essential responsibilities of a Windows Server administrator.
This guide walks through:

  • Creating a user
  • First-time login on Windows 10
  • Resetting passwords
  • Disabling and enabling accounts
  • Deleting users and seeing the authentication outcome

Each step includes screenshots for clear documentation and learning.

Note: This is a detailed post with many screenshots and multiple sections.
To navigate quickly, use your browser’s search function (Ctrl + F or Cmd + F) and look for keywords such as create, reset, enable, disable, or delete depending on the task you want to review.

Part 1 — Creating a User in Active Directory

Step 1 — Create an Organizational Unit (OU)

  1. Open Active Directory Users and Computers.
    Navigate to lab.local → New → Organizational Unit.

  1. Name the OU LabUsers and click OK.

Step 2 — Create a New User Inside the OU

  1. Click LabUsers → right-click the whitespace → New → User.

  1. Fill in the user details, including User logon name → Next.

  1. Set a temporary password.
    Enable User must change password at next logon → Next.

  1. Review the summary → Finish.

  1. Refresh ADUC. The new user appears with type User.

Step 3 — First-Time Login on Windows 10

  1. On the Windows 10 client, attempt to log in using the newly created username.

  1. Because the password must be changed, Windows prompts for a new one.

  1. Enter and confirm the new password.

  1. Password change success message appears.

  1. The desktop loads normally.

Part 2 — Resetting a User Password in Active Directory

Password resets are one of the most common administrative tasks in any environment.
These steps demonstrate how to reset a user’s password and what happens during login after the reset.

Step 1 — Locate the User in ADUC

  1. Open Active Directory Users and Computers → navigate to:
    lab.local → LabUsers

  1. Select the user who needs a password reset.

Step 2 — Reset the Password

  1. Right-click the user → Reset Password.

  1. Enter a new temporary password.
    Check User must change password at next logon → OK.

  1. A confirmation message appears.

Step 3 — First Login After Reset

  1. On the Windows 10 client, enter the new temporary password.

  1. Windows prompts for a new password.

  1. Password change completes successfully.

  1. Desktop loads normally after successful authentication.

Part 3 — Disabling and Enabling a User Account

Disabling a user account is useful when someone leaves temporarily, violates policy, or should lose access without being deleted.
This section demonstrates how disabling affects login attempts and how re-enabling restores access.

Step 1 — Locate the User

  1. In Active Directory Users and Computers, navigate to:
    lab.local → LabUsers

  1. Select the user account.

Step 2 — Disable the Account

  1. Right-click the user → Disable Account.

  1. A confirmation message appears.

Step 3 — Attempt Login on Windows 10

  1. On the client PC, attempt to log in with the disabled user.
    Windows shows the message:

“Your account has been disabled. Please see your system administrator.”

Step 4 — Enable the Account Again

  1. Return to ADUC → right-click the user → Enable Account.

  1. A confirmation message appears.

Step 5 — Login Works After Re-enabling

  1. On the Windows 10 client, log in again.
    This time it successfully loads the profile.

  1. The user reaches the Windows desktop.

Part 4 — Deleting a User from Active Directory

Deleting a user permanently removes their account from the domain.
This section shows how deletion works and what happens when the user attempts to sign in afterward.

Step 1 — Locate the User in the OU

  1. Open Active Directory Users and Computers → navigate to:
    lab.local → LabUsers

  1. Select the user you want to delete.

Step 2 — Delete the User

  1. Right-click the user → Delete.

  1. A confirmation prompt appears → click Yes.

Step 3 — Verify Deletion

  1. The user no longer appears inside the OU.

Step 4 — Login Attempt After Deletion

  1. If the deleted user attempts to sign in on Windows 10, Windows shows:

“The password is incorrect.”

  1. Using Other User, attempting to sign in again shows:

“The username or password is incorrect.”

  1. Authentication fails because the AD account no longer exists.

Conclusion

You have now completed the core user management tasks inside Active Directory, including:

  • Creating organizational units (OUs)
  • Adding new domain users
  • Handling first-time logins and password changes
  • Resetting passwords using ADUC
  • Disabling and enabling accounts
  • Deleting accounts and observing authentication behavior on a Windows client

These actions form the foundation of daily Active Directory administration.
By practicing within your homelab, you build real hands-on experience with tools and workflows used in production environments.

From here, you can explore:

  • Group Policy Objects (GPOs)
  • User profile management
  • Folder redirection and permissions
  • Multi-user organizational structures
  • Automation with PowerShell

Your AD DS lab is now ready for advanced Windows Server learning and future projects.
