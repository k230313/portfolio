Installing Windows Server on VirtualBox for a Lab

Adamson Buliboli | Dec 11, 2025 min read

Why Install Windows Server on a Virtual Machine

Installing Windows Server on VirtualBox allows you to:

  • Experiment with server administration in a safe environment.
  • Test networking and domain features without affecting your main PC.
  • Prepare a base server VM for future labs, such as Active Directory setups.

Step 1 — Download and Install VirtualBox

  1. Go to the VirtualBox website and download the installer for Windows Hosts.

  1. Install VirtualBox on your PC following the installer prompts.

Step 2 — Create a New Virtual Machine

  1. Open VirtualBox and click New.

  1. Locate your Windows Server ISO, select it, and configure VM requirements:
  • Name: DC01 (or your preferred server name)
  • Type: Microsoft Windows
  • Version: Windows Server 2022 / 2025 (64-bit)
  • RAM: 4–8 GB recommended
  • Disk: 60 GB dynamically allocated

Step 3 — Install Windows Server

  1. Start the VM → select language, time, and keyboard input → Next.

  1. Select Windows Server Standard Evaluation (Desktop Experience).

  1. Accept license terms → Next.

  1. Choose Custom: Install Windows only (advanced).

  1. Select the drive → click New to create partitions.

  1. Click OK for additional system partitions required by Windows.

  1. Select the primary partition → Next.

  1. Windows Server installation will begin.

Step 4 — Initial Configuration

  1. On the Customize Settings page, set a password for the built-in Administrator account.

  1. After installation completes, Windows Server launches Server Manager.

Step 5 — Configure Network

  1. Assign a static IP address for future lab use:
  • IP: 192.168.56.101
  • Subnet: 255.255.255.0
  • Default Gateway: N/A
  • Preferred DNS: 192.168.56.101 (self)

  1. Verify the network settings using ipconfig.

Step 6 — Verify Server Configuration

  1. Open Server Manager → Local Server.
  2. Check computer name, network settings, and other initial configurations.

Conclusion

You now have a fully installed Windows Server VM in VirtualBox with:

  • A static IP configured for lab purposes.
  • Server Manager ready for administration tasks.
  • The base setup required for future lab projects such as Active Directory or DNS labs.

This VM serves as a template server for testing, experimentation, and learning Windows Server features safely.
