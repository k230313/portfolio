Installing Windows 10 Pro on VirtualBox

Adamson Buliboli | Dec 11, 2025 min read

Why Install Windows 10 on a Virtual Machine

Installing Windows 10 Pro on VirtualBox allows you to:

  • Safely test Windows features and settings without affecting your main PC.
  • Experiment with different configurations.

Step 1 — Download the Windows 10 ISO

  1. Visit the Microsoft Media Creation Tool.
  2. Click Download tool now to start creating the installation media.

  1. Choose Create installation media (USB flash drive, DVD, ISO) for another PC.

  1. Select your language, edition, and architecture.

  1. Choose ISO file as the media.

  1. Save the ISO to a folder on your PC.

  1. Wait for the download to complete.

  1. Click Finish once the ISO is ready.

  1. Verify the ISO file is saved correctly (e.g., Windows.iso).

Step 2 — Create a New Virtual Machine in VirtualBox

  1. Open VirtualBox and click New.

  1. Name your VM (e.g., CLIENT01), select Microsoft Windows, version Windows 10 (64-bit).
  2. Allocate RAM (4 GB recommended) and virtual disk (40–60 GB, dynamically allocated).
  3. Select the ISO you downloaded as the boot disk.

  1. Confirm the VM creation and specs.

Step 3 — Install Windows 10

  1. Start the VM → Windows setup will launch.
  2. Select language, time, and keyboard → Next.

  1. Click Install Now.

  1. Choose I don’t have a product key for lab testing.

  1. Select Windows 10 Pro x64.

  1. Accept license terms → Next.

  1. Select Custom: Install Windows only (advanced).

  1. Create a new partition → Apply → OK.

  1. Select the correct partition → Next.

  1. Windows installation will begin.

Step 4 — Configure Windows 10

  1. Select your region.

  1. Choose I don’t have internet (host-only lab setup).
    (If you want internet, select NAT instead.)

  1. Continue with limited setup.

  1. Enter the username (e.g., User01) for the local account.

  1. Turn off all privacy settings → Accept.

  1. Skip Cortana setup → Not now.

  1. Windows prepares your environment.

  1. Finally, you’ll reach the Windows 10 desktop.

Conclusion

You now have a fully installed Windows 10 Pro VM in VirtualBox. The VM can be used to:

  • Test Windows features and settings in a safe environment.
  • Install and experiment with applications without affecting your main PC.
  • Learn and practice Windows configuration and troubleshooting.

This VM also serves as a template for creating additional Windows VMs for testing,
